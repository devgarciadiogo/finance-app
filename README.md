# 💰 FinanceApp

Sistema de gestão financeira pessoal desenvolvido em Java puro,
evoluindo progressivamente até uma API REST completa com Spring Boot e segurança JWT.

## 🚀 Tecnologias

- Java 17
- Maven
- Spring Boot *(em breve)*
- PostgreSQL *(em breve)*
- Spring Security + JWT *(em breve)*

## 📋 Funcionalidades

- [x] Cadastro de receitas e despesas por categoria
- [x] Cálculo automático de saldo
- [x] Relatório detalhado com maior despesa e receita
- [x] Agrupamento de gastos por categoria
- [x] Metas de gasto por categoria com alertas
- [x] Validações e exceções customizadas
- [ ] Persistência em arquivo JSON
- [ ] Banco de dados PostgreSQL
- [ ] API REST com Spring Boot
- [ ] Autenticação com JWT

## 🏗️ Estrutura do projeto

    src/
    └── main/java/com/financeapp/
        ├── model/          # Entidades do domínio
        ├── service/        # Regras de negócio
        ├── repository/     # Acesso a dados
        └── exception/      # Exceções customizadas

## 📐 Conceitos aplicados

- Orientação a Objetos (herança, polimorfismo, encapsulamento)
- Classes abstratas e interfaces
- Coleções e Streams (filter, map, reduce, groupingBy)
- Optional para tratamento seguro de nulos
- BigDecimal para precisão financeira
- Exceções customizadas e programação defensiva
